# CA-517 — фактическая геометрия фасадов (Этап 2)

Дата: 2026-11-11. Статус: **реализовано**, проверки пройдены.
Продолжение CA-T-514 (Этап 1 материалов) и CA-T-516 (legacy-каталог).
Этап 3 (фрезеровка) и Этап 4 (Gola) не начинались.

## 1. Правило расчёта

Стоимость фасадов считается по фактическим створкам:

```
area одной створки = width × height / 10 000   (м²)
frontsCost         = Σ area створок × ставка материала × стилевой множитель
```

Площадь модуля, корпуса или секции больше не подменяет площадь створок.
Тарифы и коэффициенты (`ratePerSqm`, `flat/shaker/handleless`) не менялись;
источник — действующий PriceSnapshot Calculation Admin.

## 2. Единый источник геометрии

`src/lib/configurator/facade-geometry.ts` — единственное место, где заданы
зазоры, порог деления и формулы площади. Его используют:

- Engine кухни и шкафа (`engine.ts`);
- legacy-расчёт (`pricing.ts`);
- 2D-сцены (`KitchenScene.tsx`, `WardrobeScene.tsx`);
- расчёт фасадов мойки (`sink.ts` через те же константы).

### 2.1. Зазоры и вставки

| Константа | Значение | Смысл | Источник |
| --- | ---: | --- | --- |
| `FACADE_SPLIT_WIDTH_CM` | 60 см | `width > 60` → две створки | `KitchenScene`, `WardrobeScene`, `pricing.ts` |
| `FACADE_EDGE_GAP_CM` | 0,2 см | край ряда, верх/низ поля | `KitchenScene` |
| `FACADE_NEIGHBOR_GAP_CM` | 0,1 см | стык с соседним модулем | `KitchenScene` |
| `FACADE_DOOR_GAP_CM` | 0,2 см | между распашными створками, 2 мм суммарно (по 1 мм на створку) | `KitchenScene`, `SINK_RULES.facadeInnerGap` |
| `FACADE_DRAWER_GAP_CM` | 0,2 см | между фронтами ящиков по высоте | `KitchenScene` (2 мм) |
| `FACADE_OVEN_DOOR_GAP_CM` | 0,1 см | модуль `oven`: прежний зазор до отдельного решения | `facade-geometry.ts` |
| `WARDROBE_DOOR_GAP_CM` | 0,55 см | между дверями шкафа | `WardrobeScene` |
| `WARDROBE_SIDE_REVEAL_CM` | 1,4 см | вставка корпуса по бокам | `WardrobeScene` (2,8 см на секцию) |
| `WARDROBE_TOP_REVEAL_CM` | 1,4 см | вставка сверху | `WardrobeScene` |
| `WARDROBE_BOTTOM_REVEAL_CM` | 1,2 см | вставка снизу | `WardrobeScene` |
| `WARDROBE_PLINTH_HEIGHT_CM` | 8 см | высота цоколя шкафа | `WARDROBE_LIMITS.plinthHeight` |

**CA-T-518 (2026-11-11):** центральный зазор приведён к утверждённым 2 мм суммарно (было 1 мм). Остальные значения — существующие числа 2D и `SINK_RULES`.
`SINK_RULES.facadeEdgeGap/facadeNeighborGap/facadeInnerGap` теперь ссылаются на
общие константы; собственный `SINK_RULES.facadeGap = 0,25` остаётся
конструктивным зазором перегородок/секций и на площадь створок не влияет.

### 2.2. Кухня

```
поле ширины  = width − leftGap − rightGap
leftGap      = rowStart ? 0,2 : 0,1
rightGap     = rowEnd   ? 0,2 : 0,1
поле высоты  = height − 0,2 − 0,2
              (для tall/oven height включает цоколь: height − plinth − 0,4)
створка      = (поле ширины − 0,2 × (doors − 1)) / doors
```

- Ряд определяется фактическим порядком модулей: отдельно нижний и верхний.
- Одна створка при `width ≤ 60`, две при `width > 60`.
- Модуль `oven` (встроенная техника) сохраняет прежний центральный зазор
  0,1 см до отдельного решения; остальные кухонные модули — 0,2 см.
- Мойка: ширина каждой панели берётся из существующего
  `sinkLayout().facadeBoxes`; высота — поле фасада; фронты ящиков делятся
  по высоте с зазором 2 мм.
- Ящики: ширина — поле фасада, высота `(поле высоты − 0,2 × (n − 1)) / n`.

### 2.3. Шкаф

```
поле ширины = sectionWidth − 1,4 − 1,4
поле высоты = height − plinth − 1,4 − 1,2
двери       = sectionWidth > 60 ? 2 : 1
створка     = (поле ширины − 0,55 × (doors − 1)) / doors
```

Одна секция даёт одну или две двери; итоговая площадь — сумма по всем секциям.
Ящики шкафа остаются наполнением за дверями и отдельных фасадных деталей
в модели не образуют.

## 5. Изменения поведения, требующие внимания

- `engine.sink.facadeNeighborGap` больше не инертен: мойка в середине ряда
  использует фактический соседний зазор (как и 2D). Значение по умолчанию
  не менялось (0,1 см); центральный зазор с CA-T-518 — 0,2 см суммарно.
- Площадь фасада модуля-бутылочницы теперь считается по фактической панели,
  а не по площади модуля; это влияет на разницу цен при добавлении
  бутылочницы (механизм по-прежнему тарифицируется отдельно).

## 6. UNKNOWN / требует согласования

- **OI-003 / OI-035:** в 2D шкафа проём считается как `sectionWidth − 2,8`, а
  `WARDROBE_LIMITS.carcassThickness = 2`. Для площади дверей используется
  существующее фактическое поле 2D (2,8 см). Какое значение производственно
  верно — не подтверждено; после решения владельца константы
  `WARDROBE_SIDE_REVEAL_CM/TOP/BOTTOM` должны быть пересмотрены.
- Зазоры кухни и мойки утверждены владельцем в CA-T-518: верх/низ 2 мм,
  соседний модуль 1 мм, открытый край 2 мм, между створками 2 мм суммарно.
  Зазор шкафа 0,55 см по-прежнему взят из 2D и производственно не подтверждён.
- Производственная проверка фактических допусков (кроме утверждённых правил)
  не выполнялась.
- Фрезеровка, Gola, `shaker`/`handleless`/`bodyFactor`/`complexity` и BOM
  не менялись (Этапы 3–4 не начаты).
