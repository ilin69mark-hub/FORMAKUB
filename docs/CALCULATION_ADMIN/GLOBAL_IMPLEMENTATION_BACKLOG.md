## 1. Модель состояния реализации

Три независимых состояния (подробно — `STORE_ADMIN_GAP_ANALYSIS.md` § 2):

- **IMPLEMENTED** — код, API и механизмы существуют и покрыты тестами.
- **DATA_READY** — необходимые данные фактически созданы и валидны в активном Store.
- **OPERATIONAL** — механизм подключён к рабочему процессу и может использоваться.

Отсутствие записей в Store **не означает** `MISSING`: реализованная, но не заполненная сущность —
`IMPLEMENTED` + `DATA_READY=false`.

## 6. Критический путь и последовательность

Прежняя последовательность «CA-GL-01 → CA-GL-02» **неверна**: `CA-GL-02` (Composition) не является
условием эксплуатации — pin необязателен (В-1), Engine не читает состав, трассировка независима.
